1단계 · 이메일 인증 및 계정 설정

1

Okta 사이트 접속 후 로그인

auth.corp.musinsa.com 접속 → 이메일, 공통 비밀번호(musinsa0!@T) 입력 후 로그인해주세요.

'이메일 보내기' 클릭 → 📧 Gmail에서 인증 메일을 열어 '로그인' 버튼을 클릭해주세요.

메일 제목: '일회성 확인 코드' 또는 'one-time verification code'

2

보안 설정 메뉴로 이동

우측 상단 프로필 클릭 → 계정 설정 클릭 → 하단 '보안 방법' 탭에서 Okta Verify의 '설정'을 클릭해주세요.

3

한 번 더 본인 확인

🔁 방금 한 것과 비슷해 보이지만 오타 아니에요! 새 인증 수단을 등록할 땐 보안을 위해 한 번 더 확인해요.

공통 비밀번호(musinsa0!@T) 재입력 → '이메일 보내기' 클릭 → 📧 Gmail에서 다시 '로그인' 클릭해주세요.

4

QR 코드 화면 띄우기

다시 Okta Verify '설정' 클릭 → 화면에 QR 코드가 떠요. 이 화면은 그대로 두고, 이제 스마트폰을 꺼내주세요!

📱 스마트폰

2단계 · Okta Verify 앱 설치 및 등록

5

Okta Verify 앱 설치 및 시작

App Store(iPhone) 또는 Play스토어(Android)에서 "Okta Verify" 검색 후 설치해주세요.

앱 열기 → 시작하기 → 다음 → 계정 추가 순서로 눌러주세요.

6

조직 계정으로 추가하고 QR 촬영

"조직" 선택 → (다른 장치 추가 묻는 화면에서) "건너뛰기" → "예, 스캔 준비 완료" 클릭해주세요.

스마트폰 카메라로 4단계에서 노트북에 띄워둔 QR 코드를 촬영해주세요.

7

알림 및 생체인증 설정

푸시 알림 '허용' → Face ID/지문 인증 '사용' → '완료' 클릭해주세요.

🎉

완료했어요!

Okta Verify 앱에 회사 계정이 등록됐어요. 이제 회사 시스템 로그인 시 이 앱으로 본인 확인을 하게 돼요.

📎 참고: 앞으로 로그인할 때

지금 당장 하실 건 없어요. 이후 회사 시스템에 로그인할 때 아래 두 방법 중 하나로 본인 확인을 하게 되니, 필요할 때 다시 찾아보세요.

🔢 방법 1 · 코드 입력 (OTP)

  1. 로그인 화면에서 "코드 입력" 선택
  2. Okta Verify 앱에서 잠금 박스 터치 → 생체인증(지문·FaceID)
  3. 화면에 뜨는 6자리 코드를 로그인 화면에 입력

코드는 30초마다 바뀌어요. 시간 안에 입력해주세요 (상단 파란 바가 남은 시간이에요)

🔔 방법 2 · 푸시 알림

  1. 로그인 화면에서 "푸시 알림 받기" 선택
  2. 스마트폰에 알림이 오면 터치
  3. 본인이 시도한 로그인이 맞으면 "네, 본인입니다" 터치
⚠️ 본인이 로그인을 시도하지 않았는데 알림이 온다면, 절대 승인하지 말고 정보보안실에 바로 문의해주세요.
